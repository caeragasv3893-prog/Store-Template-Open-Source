# Luxury Fashion Website Template

A responsive HTML website template designed for fashion brands, clothing stores, boutiques and independent designers.

## Features

- Modern and minimalist design
- Light and dark mode
- Front-end shopping cart
- Responsive layout for desktop, tablet and mobile
- Built with HTML, CSS and JavaScript
- Easy to customize

## Included Files

- HTML, CSS and JavaScript source files
- Website preview images

## Notes

This template is front-end only. It does not include a backend, database or payment integration.

Suitable for personal projects, fashion brands and online store presentations.
